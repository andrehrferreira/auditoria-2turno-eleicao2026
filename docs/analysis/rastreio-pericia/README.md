# Rastreio de `docs/pericia/README.md`

Índice técnico do que saiu do texto do relatório quando ele passou a ser um documento independente do processo (pedido do André, 30/10/2026; regra em `CLAUDE.md`, seção "Relatório de perícia"). **Este arquivo não entra no relatório.** Nenhum número, rótulo ou conclusão mudou; só a forma.

## Aviso inicial

- "passam pela revisão cética" virou "passam por revisão independente". A revisão independente é a do agente `cetico-revisor`, com pareceres em [`docs/analysis/cetico-revisor/`](../cetico-revisor/).

## Regra deste relatório

- "parecer do revisor cético que o sustente" virou "uma revisão independente, que tentou derrubá-lo e o confirmou". Pareceres em [`docs/analysis/cetico-revisor/`](../cetico-revisor/).
- "Esses ficam nos documentos de análise (`docs/analysis/`)" virou "Esses ficam nos documentos de trabalho, fora deste relatório". Os documentos são os de [`docs/analysis/`](../).
- Entrou a frase "Este relatório é independente: os programas, os dados intermediários e as verificações de cada número estão num índice técnico separado". O índice técnico é esta pasta (`docs/analysis/rastreio-pericia/`), mais `docs/pericia/evidencias/` (livro de registro) e os pareceres.
- Entrou a "Regra de controle (princípio 8)", texto copiado do tópico 3 (`docs/pericia/03-linha-do-tempo.md`, linha "Princípio usado"). Origem: princípio 8 de [`docs/01-premissas.md`](../../01-premissas.md). Motivo: os tópicos 2, 3 e 4 citam "princípio 8", e o leitor do PDF não tem `docs/01-premissas.md`.

## Premissa de forma

- "com o caminho para refazer cada um" virou "identificados por estado, município, zona e seção, para que cada um possa ser conferido". O caminho para refazer (scripts e comandos) está nos arquivos de rastreio de cada tópico.
- "Os dados do gráfico ficam guardados junto, com o script que os gera" virou "ficam guardados no índice técnico". Dados: `docs/pericia/graficos/dados/*.csv`; scripts: `scripts/auditoria/grafico-*.mjs` (e `grafico-*-dados.mjs`, que conferem as somas).
