# Caso ES 57037/0055/0364: rajadas de "O eleitor identificado já votou" sem voto entre elas

Origem: varredura nacional do padrão do caso [AC 01007/0009/0440](ac-01007-z0009-s0440.md) (`scripts/ja-votou-por-voto.mjs`). É a única seção do 2º turno com mais eventos "já votou" do que votos: 388 para 275. Fica na mesma zona do [caso ES 0372](es-57037-z0055-s0372.md).

## Fatos (log de 25/10/2026, horário local = Brasília)

- 275 votos computados; 388 eventos `O eleitor identificado já votou`.
- 366 desses eventos vêm **em sequência, sem nenhum voto entre eles**. São 19 rajadas de 5 ou mais (382 eventos), quase todas por **título de eleitor**:

| Rajada | Eventos | Identificador |
|---|---|---|
| 09:40 → 09:47 | 5 | 3 títulos, 2 CPF |
| 10:43 → 10:57 | 32 | título |
| **11:19 → 11:33** | **59** | título |
| 11:40 → 11:48 | 39 | título |
| 15:01 → 16:31 | 15 rajadas, de 5 a 36 eventos (247 no total) | título |

- Cada rajada termina com um eleitor habilitado e um voto computado.
- Ritmo: um identificador a cada ~10–30 s. Depois de cada `já votou`, a urna volta a `Aguardando digitação do identificador do eleitor`.

## Hipóteses (nenhuma testada)

- **H-a (consulta indevida):** o mesário usou a urna para consultar se pessoas de uma lista (o caderno?) já tinham votado.
- **H-b (busca de título livre):** alguém digitou títulos em sequência procurando um que ainda não tivesse votado. É o mecanismo descrito em H05/B1.
- **Explicações alternativas:** defeito na leitura do título ou eleitores de outra seção. Mas um eleitor de outra seção daria `não pertence à seção` ou `não encontrado`, não `já votou`.

## Próximos testes (Recomendação)

1. Medir no país inteiro a **maior rajada de `já votou` sem voto entre eles** por seção (o perfil atual só conta o total), para saber quão raro é o padrão.
2. Nesta seção: ver se os eleitores habilitados logo depois de cada rajada foram liberados **sem biometria** (ano de nascimento ou dado pessoal). Sob H-b, isso seria esperado.
3. Comparar com o 1º turno na mesma seção e com o mesário registrado no log.
4. O detalhe por eleitor (quem foi habilitado como) não sai do log; o caderno de votação só se obtém por pedido formal (doc 04).
